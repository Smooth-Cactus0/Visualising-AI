ViT explorer, in 3D

The toy Vision Transformer of the 2D explorer, drawn as blocks of cubes, one cube per number. Each token sits where its patch was: the 16 tokens make a 4×4 block whose depth is the token's 8 numbers, the shape of a CNN feature map. Each head's attention map is a slab of 16 little 4×4 maps, one at each token's place, showing where in the image that token looks. Cube size is magnitude and colour is sign (blue negative, orange positive). Drag to orbit, scroll to zoom, right-drag to pan. Hover a cube to see what it is computed from; click to pin it while you turn the view.
